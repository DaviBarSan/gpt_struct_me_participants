```python
import re

def extrair_participantes(texto):
    # Regras para identificar participantes
    regras = [
        r"(\w+ de \w+ anos)",  # Um homem de 20 anos
        r"(\w+ de \w+)",  # Droga, PSP, etc.
        r"(\w+ no \w+)",  # Bairro, Porto, etc.
        r"(\w+ da \w+)",  # Comando Metropolitano do Porto, etc.
        r"(\w+ no \w+)",  # Ação policial, etc.
        r"(\w+ da \w+)",  # Fiscalização, etc.
        r"(\w+ no \w+)",  # Embarrcação, etc.
        r"(\w+ do \w+)",  # César Maphossa, etc.
        r"(\w+ no \w+)",  # Fiscais, etc.
        r"(\w+ no \w+)"  # Autoridades, etc.
    ]

    # Buscar todos os participantes em cada texto
    participantes = []
    for regra in regras:
        participantes.extend(re.findall(regra, texto))

    # Remover participantes repetidos
    participantes = list(set(participantes))

    return participantes

# Testar a função
texto1 = "PSP detém suspeito de tráfico de droga e apreende arma de fogo no Porto"
texto2 = "Autoridades moçambicanas apreendem mais de uma tonelada de caranguejo"

participantes1 = extrair_participantes(texto1)
participantes2 = extrair_participantes(texto2)

print("Participantes do texto 1:", participantes1)
print("Participantes do texto 2:", participantes2)
```

Este código define uma função `extrair_participantes` que recebe um texto como entrada e retorna uma lista de participantes identificados no texto. A função usa uma lista de regras para identificar os participantes, que inclui palavras e expressões que descrevem pessoas, lugares, organizações e eventos.

O código também remove participantes repetidos da lista final.
