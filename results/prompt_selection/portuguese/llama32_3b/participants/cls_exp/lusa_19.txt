Para classificar e extrair os participantes, utilizarei uma abordagem que envolve a extração de entidades e classes com base nos textos fornecidos. A classificação será feita com base nas classes fornecidas:

- Person
- Organization
- Object
- Location
- Nature
- Facility
- Other

Aqui está o código Python para realizar essa tarefa:

```python
import re
import json

def extract_entities(text):
    entities = []
    # Person
    person_pattern = r"(\w+ de \d+ anos)"
    persons = re.findall(person_pattern, text)
    for person in persons:
        entities.append([person, "Person"])
    
    # Organization
    org_pattern = r"(\w+ da \w+)"
    orgs = re.findall(org_pattern, text)
    for org in orgs:
        entities.append([org, "Organization"])
    
    # Object
    obj_pattern = r"(\w+ de fogo|heroína|cocaína|uma coluna de som|uma arma de fogo|222 euros em dinheiro|um ‘tablet’|quatro munições|cerca de \d+ doses individuais)"
    objects = re.findall(obj_pattern, text)
    for obj in objects:
        entities.append([obj, "Object"])
    
    # Location
    loc_pattern = r"(\w+ do \w+|Fervença|Alcobaça|Leiria|distrito de Leiria)"
    locations = re.findall(loc_pattern, text)
    for loc in locations:
        entities.append([loc, "Location"])
    
    # Nature
    nature_pattern = r"(sinais de ter sido amarrado|indícios de suicídio)"
    natures = re.findall(nature_pattern, text)
    for nature in natures:
        entities.append([nature, "Nature"])
    
    # Facility
    facility_pattern = r"serviço de Medicina Legal"
    facilities = re.findall(facility_pattern, text)
    for facility in facilities:
        entities.append([facility, "Facility"])
    
    # Other
    other_pattern = r"(\w+ que vive perto da vítima|uma familiar|comandante|destacamento|agência|polícia)"
    others = re.findall(other_pattern, text)
    for other in others:
        entities.append([other, "Other"])
    
    return entities

def main():
    text1 = "PSP detém suspeito de tráfico de droga e aprende arma de fogo no Porto"
    text2 = "Homem encontrado morto em Alcobaça com marcas de ter estado amarrado"

    entities1 = extract_entities(text1)
    entities2 = extract_entities(text2)

    all_entities = entities1 + entities2

    print(json.dumps(all_entities, indent=4))

if __name__ == "__main__":
    main()
```

Este código define uma função `extract_entities` que extrae as entidades dos textos fornecidos com base nas padrões de busca. Em seguida, define uma função `main` que chama a função `extract_entities` para os textos fornecidos e imprime as entidades resultantes em formato JSON.
