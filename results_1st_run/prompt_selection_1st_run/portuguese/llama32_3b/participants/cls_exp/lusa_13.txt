Para resolver esse problema, podemos usar Python com suas bibliotecas regular expression e json.

 Primeiro, vamos definir os padrões de classificação de cada classe:

```python
import re

# Padrões de classificação
classes = {
    'Person': r'[\w\s]+ de [\w\s]+ anos',
    'Organization': r'[\w\s]+ da [\w\s]+',
    'Object': r'[\w\s]+ de [\w\s]+',
    'Location': r'[\w\s]+, [\w\s]+',
    'Nature': r'\w+',
    'Facility': r'[\w\s]+ da [\w\s]+',
    'Other': r'[\w\s]+'
}
```

Em seguida, vamos criar uma função para classificar cada entidade:

```python
def classificar_entidade(entidade):
    for classe, padrão in classes.items():
        if re.search(padrão, entidade):
            return [entidade, classe]
    return [entidade, 'Other']
```

Agora, podemos usar essa função para classificar todas as entidades do texto:

```python
def classificar_todos_entidades(texto):
    entidades = re.findall(r'[\w\s]+', texto)
    classificados = []
    for entidade in entidades:
        classificado = classificar_entidade(entidade)
        classificados.append(classificado)
    return classificados
```
